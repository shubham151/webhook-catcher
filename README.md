# Webhook Catcher

**Live URL:** [https://catch.oneforalllabs.com](https://catch.oneforalllabs.com)

## What is it?
Webhook Catcher is a real-time developer utility for capturing and inspecting incoming HTTP requests and webhook payloads.

## What does it do?
When a developer opens the tool, it instantly generates a unique URL. This URL can be pasted into third-party services (like Stripe, GitHub, or Shopify). When the third-party service fires a webhook at the URL, the Webhook Catcher captures it and instantly displays a beautifully formatted breakdown of the HTTP headers, method, and JSON body in the browser for easy debugging.
